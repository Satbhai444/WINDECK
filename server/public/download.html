Setup Instructions

1

Install the PC Server

Extract the downloaded WinDeck-PC-Server.zip file on your Windows computer. Open the folder and double-click WinDeck Server.exe to start it.

⚠️

If Windows Defender shows a "Windows protected your PC" warning, click More info and then Run anyway.

2

Install the Android App

Transfer the WinDeck-Android-App.apk to your phone. Tap the file to install it. Ensure your phone is connected to the same Wi-Fi network as your PC.

3

Connect Your Devices

When you run the PC Server, a 6-digit Pairing Code will appear on your screen.

123456

Open the WinDeck app on your Android phone. It will automatically find your PC. Tap it and enter the 6-digit code to pair. You're done!
