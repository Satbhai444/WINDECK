01. The Project

WinDeck

My flagship internship project developed during the 45-day program at Prax Info.

Platform: Windows & Android

The Concept

A wireless PC control suite that transforms any Android smartphone into a powerful macro-pad. It was built to eliminate the need for expensive dedicated hardware for productivity and remote control.

The Execution

Developed from scratch utilizing advanced Prompt Engineering. By effectively directing AI tools, I was able to architect both the Node.js desktop environment and the complex Flutter UI structure within the timeframe.

03. Capabilities

Key Features of WinDeck

Remote App Launcher

Automatically fetches installed PC applications and allows users to launch them instantly with a single tap from their smartphone.

Live System Monitor

Displays real-time Windows PC statistics on the phone, including CPU usage, RAM utilization, and active foreground applications.

Secure OTP Authentication

Protects the PC from unauthorized local network access by requiring a dynamic 6-digit PIN before the phone can establish a connection.

Media & Custom Macros

Provides global media controls (Play/Pause/Skip) and the ability to execute custom PowerShell macros directly from the mobile interface.

04. Workflow

How To Use WinDeck

WinDeck operates as a synchronized dual-platform system. It requires the installation of two separate components to function securely over a local network.

Setup Phase

1

Install the WinDeck Server application on your Windows PC.

2

Install the WinDeck Mobile App on your Android smartphone.

3

Ensure both devices are connected to the same Wi-Fi network.

Connection Phase

4

Launch the mobile app. It utilizes UDP Broadcasts to automatically discover your PC.

5

Select your PC and enter the secure Pairing PIN displayed on the Windows screen.

6

Authentication is complete. You can now securely control your PC.
