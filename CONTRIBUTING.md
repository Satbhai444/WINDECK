# Contributing to WinDeck

First off, thank you for considering contributing to WinDeck! It's people like you that make WinDeck such a great tool.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create a new issue using the **Bug Report** template. Ensure you provide:
- Your PC and Android OS versions
- The exact steps to reproduce the issue
- The WinDeck app version you are using

### Suggesting Enhancements
If you have an idea for a new feature, please submit an issue using the **Feature Request** template.

### Pull Requests
1. Fork the repo and create your branch from `master`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Issue that pull request!

## Local Development Setup

### PC Server (Electron)
1. Navigate to the `server` directory
2. Run `npm install`
3. Run `npm start` to run in development mode

### Android App (Flutter)
1. Install the Flutter SDK (version 3.29.0+)
2. Navigate to the `android` directory
3. Run `flutter pub get`
4. Connect an Android device and run `flutter run`
